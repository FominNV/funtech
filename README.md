## Описание

Проект для тестового задания **funtech**.

## Разработка проекта

```bash
# Установка пакетов
$ yarn install
```

```bash
# Запуск разработки поректа
$ yarn dev
```

### Сборка приложения

```bash
# Запуск локальной сборки
$ yarn build
```

```bash
# Запуск локального тестирования собранного приложения
$ yarn start
```

```bash
# Сборка и запуск docker образа (3000 port)
$ docker compose up --build
```
